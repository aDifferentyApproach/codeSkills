# 设计思想目录

用法：方案筛选时扫描"信号"列定位适用思想（一题可选多种组合）；形态列给出变形方向，动手写码时查 examples/ 同名文件取骨架（未建者随测试增补）。

| 族 | 思想 | 本质 | 信号（何时想起） | 形态 |
|---|---|---|---|---|
| 消重复 | 分治 | 拆同类子问题、递归合并 | 可分解为独立同类子实例 | 拆分-治理-合并，基例终止 |
| 消重复 | 动态规划 | 重叠子问题 + 最优子结构 | 求最优/计数/"第 n 个"递推形 | 状态→转移方程→递推序；变种：01/完全背包、区间、树形 |
| 消重复 | 记忆化 | DP 的递归形态 | 同 DP，递归直写更自然 | lru_cache 包裹 DFS；自底向上迭代常数快数倍（p10/p87 实测） |
| 结构剥削 | 哈希索引化 | 空间换 O(1) 查询 | 频繁成员检查、去重、按键分组 | dict/set 预建索引；只查一次不值得建（见处置规则） |
| 结构剥削 | 双指针/滑动窗口 | 有序或单调消去一维 | 有序数组两头收敛；连续子串约束最值 | 对撞指针；右扩左收 + 条件维护 |
| 结构剥削 | 前缀和/差分 | 预计算使区间查询 O(1) | 频繁区间求和；区间批量更新 | cumulative 数组查询；差分数组做更新 |
| 结构剥削 | 单调栈/单调队列 | 栈内维持单调换 O(n) | 右侧第一个更大/更小；滑窗最值 | 递减栈求 next greater；单调队列保窗口最大 |
| 结构剥削 | 排序预处理 | 先排序消序维度 | 区间、配对、贪心前置问题 | 按关键字排序后一次扫描 |
| 结构剥削 | 扫描线 | 区间关系转事件排序扫描 | 重叠、覆盖、并发数、区间合并 | 起点 +1 终点 -1 事件，扫过计数 |
| 暴力优雅化 | 二分查找 | 搜索空间每次减半 | 有序数组；判定结果单调 | lo/hi 收敛，注意边界取整 |
| 暴力优雅化 | 二分答案 | 对答案值域二分 | 最小化最大/最大化最小；判定易验证 | check(mid) 单调则二分 |
| 暴力优雅化 | 堆 | 部分有序维护第 k 大 | Top-k、流式中位数、多路归并 | 小顶堆保 k 个；双堆对半维护中位数 |
| 暴力优雅化 | 并查集 | 动态连通性近 O(1) | 分组、合并、环检测、连通分量 | parent 数组 + 路径压缩 + 按秩合并 |
| 暴力优雅化 | 回溯 | DFS + 剪枝枚举 | 组合/排列/子集枚举；约束满足 | 选择-递归-撤销，约束提前剪枝 |
| 编码压缩 | 位运算 | 状态压位、异或消去、模 k 计数 | 集合状态；成对消去；计数取模 k | 掩码编码；异或配对消元；三态位计数（骨架见 examples/bit-counting.md） |
| 编码压缩 | 状态压缩 DP | DP × 位运算，集合作状态 | n ≤ 20 的选/不选最优 | dp[mask] 转移 |
| 编码压缩 | 字符串专用 | 串结构专用算法 | 多模式匹配、前缀查询、重复结构 | KMP 失配函数；Trie 前缀树；Z 函数 |
| 直取转化 | 闭式公式 | 完全结构由输入定义直取 | 输入有完全结构（连续、等差） | 数学恒等式；须过精度核验（见处置规则公式条款） |
| 直取转化 | 数学工具 | 数论与组合恒等式直算 | 整除计数、幂次模、排除计数 | 欧几里得；快速幂；容斥；筛 |
| 直取转化 | 问题转化/对偶 | 转成已知形态求解 | 原形态难解但存在同构 | 构图转最短路；离线转排序；对偶互化 |
| 选择策略 | 贪心 | 局部最优，交换论证保正确 | 排序后存在显然的当前最优 | 按策略排序 + 一次扫描；必须验证成立（反例检查） |
